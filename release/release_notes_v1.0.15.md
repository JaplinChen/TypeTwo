## 重點更新

- **修正升級安裝時無法關閉舊版 TypeTwo 的問題**：安裝程式現在會在覆蓋檔案前結束正在執行的 `TypeTwo.exe`，避免系統匣常駐程序鎖住檔案導致安裝中斷
- **延續 v1.0.14 修正**：保留越南文 đầy đủ dấu prompt、production guard、部署文件、帳號 API 與 smoke test 強化

## 安裝方式

- 下載下方 `setup_typetwo.exe`
- 若舊版安裝程式卡在「無法自動關閉所有應用程式」，請先按「取消安裝」，再改用本版 installer
- 執行安裝後，從開始選單啟動 TypeTwo

## 建議升級對象

- 升級安裝時遇到 `TypeTwo.exe` 無法關閉或檔案被占用的使用者
- 已安裝 v1.0.14 且需要重新安裝或覆蓋升級的使用者
