## 重點更新

- **可調整同步空間順序**：雲端同步頁與詞彙表同步列均新增排序按鈕，可拖曳調整同步空間顯示順序，設定會自動儲存並在所有同步位置一致呈現。
- **合併「本機雲端資料夾」與「公司檔案伺服器」**：原本分開的兩個選項合併為「本機或公司檔案伺服器」，支援 OneDrive、Dropbox、Google Drive 本機資料夾，也支援公司 UNC 路徑（`\\server\share`）。舊版設定自動遷移，無需重新設定。
- **修正 WebDAV URL 格式錯誤**：輸入 UNC 路徑（如 `\\server\share`）到 WebDAV URL 欄位時，現在會顯示明確提示，要求輸入 `http://` 或 `https://` 開頭的網址，避免無效 URI 解析錯誤。
- **修正 WebDAV Basic Auth 邏輯**：帳號與密碼均填寫時才傳送 Authorization 標頭，避免只填密碼時送出格式錯誤的認證字串。

## 安裝方式

- 下載下方 `setup_typetwo.exe`
- 執行安裝後，從開始選單啟動 TypeTwo

## 建議升級對象

- 使用 WebDAV 同步且曾遇到「不支援的 URI 格式」錯誤的使用者
- 希望自訂同步空間顯示順序的使用者
- 使用公司內部檔案伺服器（UNC 路徑）同步詞彙表的使用者
