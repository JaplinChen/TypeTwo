## 重點更新

- **各 Provider 參數獨立儲存**：切換 Provider 時自動保存目前的 API Key、Endpoint、模型與備援模型；切回時自動還原，不再需要重新輸入
- **移除 LM Studio**：LM Studio 的 OpenAI 相容模式已由原生 OpenAI provider 完整覆蓋，移除重複項目

## 安裝方式

- 下載下方 `setup_typetwo.exe`
- 執行安裝後，從開始選單啟動 TypeTwo
- 若要自動安裝 Ollama 與模型，可執行安裝目錄內的 `install_ollama_and_model.bat`

## 建議升級對象

- 同時使用多個 Provider（Gemini、Groq、OpenAI 等）並需要快速切換的使用者

## 已知限制

- 目前仍以 Windows 版本為主
- iOS 版本尚未開始開發
