```
① 選取任意文字          ② 按 Ctrl+Alt+T         ③ 直接貼上
  (任何 App)               (全域熱鍵)

  請問明天的會議幾點開始？  ──────────────►  請問明天的會議幾點開始？
                                            Cuộc họp ngày mai bắt
                                            đầu lúc mấy giờ ạ?

                                                 ↓ 貼進 Teams / Line / 任何輸入框
```

## 主要功能

```
翻譯
 ├─ 雙語輸出 ────── 原文 + 譯文同時貼回剪貼簿
 ├─ 智慧切換 ────── 偵測到中文 → 自動切換翻成越南語（或其他語言）
 ├─ 備援模型 ────── 主模型失敗 → 自動試下一個
 └─ 翻譯糾錯 ────── 結果有誤 → 點按糾錯 → 一鍵存入詞彙表

詞彙表
 ├─ 固定術語 ────── 特定詞彙永遠翻成你要的版本
 ├─ 搜尋 / 篩選 ── 支援多關鍵字同時搜尋
 ├─ 匯入 / 匯出 ── CSV / TSV / JSON 格式
 └─ 雲端同步 ────── 多裝置 / 多人共用（見下方）

系統
 ├─ 系統匣常駐 ─── 背景執行，隨時待命
 ├─ 自動更新 ────── 啟動時靜默檢查新版
 └─ 限定 App ─────  只在指定程式內觸發（例：Teams.exe）
```

## 安裝

從 [GitHub Releases](https://github.com/JaplinChen/TypeTwo/releases/latest) 下載 `setup_typetwo.exe` → 執行 → 從開始選單啟動。

升級安裝時自動關閉舊版再覆蓋，不需手動結束程式。

**使用 Ollama（本機免費）：**

```bat
package\install_ollama_and_model.bat
```

---

## 建置 / 開發

```
typetwo_flutter/   Flutter 主程式（UI、熱鍵、系統匣）
backend/           FastAPI 詞彙表後端
installer/         Inno Setup 腳本
```

```bat
build_all.bat      # 輸出 installer\output\setup_typetwo.exe
```
